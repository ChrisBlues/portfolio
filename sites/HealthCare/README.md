🏥 HealthCare — Template HTML/CSS/JS
Un site vitrine moderne et responsive inspiré du tutoriel de PraRoz, entièrement revisité, corrigé et harmonisé.
Ce projet m’a permis d’explorer la structure d’un site médical, d’améliorer la navigation mobile, d’optimiser les animations et de clarifier le code pour un rendu propre et cohérent.

✨ Fonctionnalités
- Design responsive (desktop, tablette, mobile)
- Menu mobile avec icône hamburger
- Bouton back‑to‑top animé
- Sections structurées : accueil, services, équipe, contact…
- Utilisation de Bootstrap Icons
- Code HTML/CSS/JS nettoyé et réorganisé

🛠️ Technologies utilisées
- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- (Optionnel) Toute autre librairie que tu as utilisée

🚀 Objectif du projet
Ce projet a été réalisé dans le cadre de mon apprentissage du développement web.
Il m’a permis de :
- comprendre et corriger un template existant
- améliorer la gestion du responsive
- résoudre des problèmes concrets (menu mobile, back‑to‑top, préloader inutile)
- renforcer mes bonnes pratiques de structure et de clarté du code
