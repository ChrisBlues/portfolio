# TravelToor

**Partir loin, revenir transformé.**

TravelToor est une agence de voyages imaginée par **Web Design Mastery**, pensée comme une invitation à explorer le monde avec élégance et intention.  
Ce projet célèbre le mouvement, la découverte et la transformation intérieure que chaque voyage inspire.

✨ Symbole
Une ligne continue formant un horizon ouvert, une boussole stylisée, et une flèche subtile vers l’avenir.
Le tracé existe aussi en version micro‑logo dégradé doré‑bleu, optimisée pour les très petites tailles.

✨ Concept éditorial
TravelToor raconte le voyage comme un rituel :
Partir loin, revenir transformé.

Chaque destination devient une expérience intérieure, chaque retour une renaissance.
Le design s’efface pour laisser place à la sensation : fluidité, lumière, mouvement.

🧭 Création
- Design & direction artistique : Web Design Mastery
- Palette : sable doré, lumière pêche, horizon bleu
- Typographie : sobre, lisible, élégante
- Symbole : ligne continue, abstraite, évocatrice

TravelToor s’inscrit dans une collection de projets où le design devient récit.
Chaque détail — couleur, ligne, mot — participe à une même intention :
