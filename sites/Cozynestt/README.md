🧵 Cozynestt — Boutique artisanale & design chaleureux
Cozynestt est une landing page e‑commerce élégante, chaleureuse et artisanale, réalisée en HTML, Tailwind CSS et JavaScript.
Ce projet met en avant un design doux, cosy, inspiré des matières naturelles, avec une attention particulière portée aux détails visuels et à l’expérience utilisateur.

Ce site est une reproduction pédagogique du travail exceptionnel de CodeWithSadee, dont je remercie profondément la qualité du design, la précision du code et la générosité du partage.

✨ Aperçu du projet
Design chaleureux, inspiré des tons crème, miel et ambre

Sections fluides et harmonieuses

Animations douces et transitions élégantes

Mise en page responsive fidèle au modèle original

Images optimisées et structure propre

Le résultat est une page moderne, raffinée, agréable à parcourir, qui met en valeur l’univers artisanal et cosy de la marque.

🎨 Technologies utilisées
Tailwind CSS
Cozynestt repose entièrement sur Tailwind CSS pour :

une mise en page rapide et flexible

une palette de couleurs personnalisée

des animations sur mesure

un responsive design précis

une structure de classes claire et maintenable

Le fichier tailwind.config.js a été enrichi pour intégrer :

des couleurs personnalisées

des breakpoints adaptés

des animations spécifiques

des ombres et effets visuels cohérents avec le design

HTML5
Structure sémantique propre, sections bien organisées, code lisible.

JavaScript
Interactions légères :

menu mobile

sliders

animations

comportements dynamiques

🛠️ Installation & développement
npm install
npm run dev
Le projet utilise Tailwind CLI pour compiler input.css en output.css.

🌐 Déploiement
Le site est déployé via GitHub Pages, directement depuis la branche main.
