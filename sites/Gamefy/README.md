# Gamefy — Cover Game Showcase

Gamefy is a modern, stylish gaming showcase built as part of a Fun Coding tutorial.  
This project highlights **Cover Game**, a fictional action‑strategy title presented through a clean, responsive interface designed for gamers.

The goal of this project is to practice layout structure, component organization, and UI polish while creating a visually engaging mini‑platform for game discovery.

---

## 🚀 Features

- **Hero section** introducing the Cover Game universe  
- **Top products** cards inspired by Gensin Impact 3.3  
- **Latest games gallery** with a clean grid layout  
- **Newsletter subscription section**  
- Fully responsive design  
- Smooth, modern visual style suitable for gaming content

---

## 🕹️ About Cover Game

Cover Game is presented as a fast‑paced, strategic adventure where every move matters.  
The platform showcases the game through dynamic visuals, short descriptions, and curated highlights to simulate a real gaming storefront experience.

This project does not aim to reproduce a full game — instead, it focuses on **UI/UX practice**, **content structure**, and **front‑end creativity**.

---

- **HTML5**  
- **CSS3** (Flexbox, Grid, responsive layout)  
- **JavaScript** (basic interactivity)  
- **Google Fonts & icons**

# Gamefy — Présentation de Cover Game

Gamefy est une vitrine de jeux moderne et élégante, créée dans le cadre d'un tutoriel de programmation ludique.

Ce projet met en avant **Cover Game**, un jeu d'action-stratégie fictif présenté via une interface épurée et réactive, conçue pour les joueurs.

L'objectif de ce projet est de s'exercer à la structure de la mise en page, à l'organisation des composants et au raffinement de l'interface utilisateur, tout en créant une mini-plateforme visuellement attrayante pour la découverte de jeux.

---

## 🚀 Fonctionnalités

- **Section principale** : présentation de l'univers de Cover Game

- **Meilleurs produits** : cartes inspirées de Gensin Impact 3.3

- **Galerie des derniers jeux** : mise en page claire et structurée

- **Inscription à la newsletter**

- Design entièrement réactif

- Style visuel moderne et fluide, idéal pour le contenu de jeux

---

## 🕹️ À propos de Cover Game

Cover Game est présenté comme une aventure stratégique et dynamique où chaque action compte. La plateforme met en valeur le jeu grâce à des visuels dynamiques, de courtes descriptions et une sélection de contenus phares, afin de recréer l'expérience d'une véritable boutique de jeux vidéo.

Ce projet ne vise pas à reproduire un jeu complet ; il se concentre plutôt sur la pratique de l'**interface utilisateur/de l'expérience utilisateur**, la **structure du contenu** et la **créativité du développement front-end**.
