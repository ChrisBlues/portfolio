# Travelvideos

Travelvideos est une petite démonstration web inspirée d’un tutoriel de Coding Snow.  
Le projet présente une section d’accueil immersive avec une vidéo en arrière‑plan, un voile coloré pour créer une ambiance visuelle cohérente, ainsi qu’un texte animé qui apparaît progressivement.

## 🎯 Objectifs du projet

- Découvrir et pratiquer l’intégration d’une vidéo en arrière‑plan.
- Comprendre l’utilisation des pseudo‑éléments (`:before`) pour créer des effets visuels.
- Expérimenter les animations simples en JavaScript (activation du texte).
- Structurer une page moderne avec HTML, CSS et JS.
- Publier un projet sur GitHub Pages.

## 🧩 Fonctionnalités

- **Vidéo plein écran** en arrière‑plan.
- **Voile coloré** pour harmoniser les couleurs et améliorer la lisibilité.
- **Texte animé** qui apparaît progressivement.
- **Footer de remerciements** avec lien vers le tutoriel original.
- **Responsive design** simple.

## 🛠️ Technologies utilisées

- **HTML5**
- **CSS3**
- **JavaScript**
- **Git & GitHub**
